# SpeechToText 🎤📝

This is a small web app that allows the user to convert speech to text.  It's perfect for situations where typing is inconvenient or if you're unsure of the spelling of a word.  Just speak, and let the app do the typing for you!

## Features ✨

* **Real-time Transcription:**  Converts speech to text instantly as you speak.
* **Punctuation Support:** Automatically adds punctuation to the transcribed text (periods, commas, question marks).
* **Copy to Clipboard:** Easily copy the transcribed text to your clipboard with a single click.
* **Multiple Language Support:**  Transcribes speech in various languages (e.g., English, Spanish, French - specify supported languages).
* **User-Friendly Interface:** Simple and intuitive design for a seamless user experience.

## Technologies Used 💻

* **HTML5:**  For structuring the web page.
* **CSS3:** For styling the web page.
* **JavaScript:**  For the core speech recognition and text manipulation logic.
* **Web Speech API:** The browser API for accessing speech recognition functionality.


## Installation 💾

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/DamDev1/speechToText.git
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd speechToText
   ```

3. **Open `index.html` in your browser:**  You can simply double-click the `index.html` file or open it from your browser's file menu.  No server setup is required as this project is purely client-side.


## Usage 🚀

1. **Open the web app in your browser.**
2. **Click the "Start Recording" button** (or similar - name the button element in your app appropriately).  Your browser may ask for permission to access your microphone; grant it.
3. **Start speaking clearly.** The transcribed text will appear in the designated text area in real-time.
4. **Click the "Stop Recording" button** when you're finished.
5. **Copy the text to your clipboard** using the provided button or by selecting and copying manually.

**Example:**  Say "Hello, world! This is a test of the speech-to-text application."  The text area should display the same sentence, including the punctuation.
